# Observability

Guides for instrumenting, monitoring, and troubleshooting production systems using OpenTelemetry, SigNoz, and modern logging pipelines.

Browse the guides in this section to build end-to-end observability across your applications and infrastructure.

## Available Guides

### Instrument BookStack with OpenTelemetry and SigNoz

Deploy BookStack with OpenTelemetry instrumentation and export distributed traces to SigNoz using Docker for end-to-end observability.

**→ Read:** [Instrument BookStack with OpenTelemetry and SigNoz](/docs/observability/bookstack-signoz)



### Instrument a Node.js Express App with OpenTelemetry and SigNoz

Build an Express.js application instrumented with OpenTelemetry, integrate PostgreSQL and Redis, and visualize HTTP requests, database queries, and cache operations in SigNoz.

**→ Read:** [Instrument Node.js Express App with OpenTelemetry and SigNoz](/docs/observability/nodejs-express-signoz)



### Build an OpenTelemetry Collector Pipeline with Docker Compose and SigNoz

Build a central telemetry pipeline using the OpenTelemetry Collector and Docker Compose, then connect it to SigNoz to receive, process, and export traces, metrics, and logs.

**→ Read:** [Build an OpenTelemetry Collector Pipeline with Docker Compose and SigNoz](/docs/observability/opentelemetry-collector-article)

## What You'll Learn

- Instrument applications with OpenTelemetry to collect traces, metrics, and logs
- Export telemetry data to SigNoz for visualization and analysis
- Build a central telemetry pipeline with the OpenTelemetry Collector
- Monitor HTTP requests, database queries, and cache operations
- Troubleshoot application performance using end-to-end observability
